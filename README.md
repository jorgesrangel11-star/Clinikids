#  Clinikid's (Peditech) - Plataforma de Gestión Pediátrica

Plataforma integral (web y móvil) diseñada para modernizar y agilizar la administración de clínicas pediátricas. El sistema permite la digitalización completa de consultas, gestión de expedientes médicos en tiempo real y seguimiento detallado de pacientes.

##  Características Principales

* **Gestión de Expedientes:** Creación y actualización de historiales médicos de forma digital y centralizada.
* **Formularios Dinámicos:** Interfaces optimizadas para agilizar la captura de datos por parte del personal médico durante las consultas.
* **Seguimiento de Pacientes:** Monitoreo del estado, citas y tratamientos del área pediátrica.
* **Interfaz Intuitiva:** Diseño enfocado en la usabilidad (UI/UX) para reducir tiempos de atención.

## Tecnologías Utilizadas

* **Frontend:** React, JavaScript (ES6+), HTML5, CSS3
* **Diseño/Prototipado:** Balsamiq
* **Control de Versiones:** Git & GitHub
